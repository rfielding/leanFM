Catching the specification and the Zig implementation up to upstream 72c11f5, 2026-11-21
Upstream https://github.com/rfielding/maqam moved 30 commits past the snapshot c80b35d. impl/rust/source
now holds 72c11f5 (same exclusions as before: .github, the demo mp4, the project's own Makefile).

What changed upstream and is now required (spec/Requirements.lean, book/main.tex):
  - vol <bus> <0..2> (all, mic, bass, kanun, drums, sym), dry <0..100>, both live (.globals.ml) and,
    through i/edit, timeline rows saved as L|id|vol and D|id|dry
  - cab vintage|modern|open [mix 0..1] / cab off, a cabinet FIR stage after NAM; fx off turns it off
  - NAM on selects only the modeled input (no parallel clean signal); the mic bus is trimmed linearly
    after the clip; the dry mix is applied last
  - nam gain 0..100 (help text still says 0..8: recorded under doc disagreements)
  - the church modes (Minor, Ionian, Dorian, ...) are Pythagorean
  - --bufsize=<frames>, default 64 (the commit message says 256)
  - live input backlog bounded (new never-requirement "Live input never lags behind a backlog")
  - LLM NAM research tries TONE3000 search first; "find ... and set it here" is an edit request
