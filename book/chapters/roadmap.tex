\section*{Self-hosting consolidation}

The canonical requirements entry point now composes the existing LeanFM ChatUI
specification with a proposed revision-bound requirements-to-PR workflow. The
Worker protocol remains an example, not a specification of the whole product.
\texttt{make selfhost-check} validates the typed composition and regenerates
\texttt{SELF\_HOSTING\_REVIEW.md}, including its interaction diagram and state
machine. A component registry and fresh-session handoff preserve decisions
without requiring conversation history.

The consolidation proposes checker outcomes, check invalidation, probability
interpretations and PR evidence. Earlier proposals also cover modal indexes;
built-in knowledge and policy checking is now deferred. These records are not
implemented features or proofs. Error protocols, formula semantics and complete
traceability remain prerequisites for a complete one-shot specification.

\section{Proof obligations}

The initial metatheory is session-type metatheory with the channel physics
added. It should make the following questions precise:

\begin{itemize}
  \item Which global types are well formed: every choice directed by one role,
        and every role that must learn a branch either told by a message or
        released by a declared timer?
  \item Does projection to local types preserve the global type, so that roles
        following their local types over the declared channels produce only
        runs of the global type (session fidelity)?
  \item Which channel physics preserve communication safety and progress, and
        which (loss, duplication, early timers) require the protocol itself to
        recover, as TFTP's retransmission does?
  \item Does a recorded production event stream conform to the global type, and
        does each event's \texttt{causeId} stay within its sender's own
        history?
  \item Under what finiteness restrictions is CTL checking decidable and executable?
  \item Which guards can be compiled into finite monitor state?
  \item When does modular composition preserve an established temporal property?
  \item Which fairness and timing assumptions are required by a liveness theorem?
  \item Which observation and policy relations justify each knowledge,
        permission, and obligation assertion, and which bounds make their
        combination with CTL executable?
\end{itemize}
