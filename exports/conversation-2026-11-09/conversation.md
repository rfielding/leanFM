# Appendix A. Checked correction

The following is the completed correction, added as an export appendix rather than attributed to an earlier assistant reply.

**Scope and assumption.** The chapter’s lost-letter observation ends before address receipt. The revised protocol preserves that observation as an incomplete prefix and adds a possible later direct resend. Completion requires that recovery; the model does not prove the tenant will actually resend. Permanent waiting remains an unfinished observation, not a completed branch. No delivery notification or forwarding address is invented within the original recorded horizon.

**Positive invariant.** The landlord follows the same receive-and-settle behavior whether an earlier postal attempt occurred or not.

**Negative requirements.** The lost-letter prefix must not count as complete. Deposit return must not precede receipt of the forwarding address in that branch. The correction must not remove the chapter’s unlawful outcomes.

**Control and evidence.** Both address branches have the same landlord projection; the recovery branch requires ForwardingAddress before settlement. Structural checks pass, the three completed source scenarios still conform, and negative conformance checks reject premature completion and return.

## Source qualifications retained

Finite histories do not uniquely determine a protocol. The reconstruction serializes one ordering of events; it does not prove every sequential order is mandatory. In the source, hardship events at days 330 and 332 appear in the list after LeaseEnded at day 365; the reconstruction uses chronological order consistent with predecessor constraints. BelievesViolated is represented as a local Tenant event.

The source’s `act2` evaluator checks DepositReturned rather than DeductionsItemized independently. Both occur on day 372 in the itemised example, so that example does not expose the difference from the prose rule.
